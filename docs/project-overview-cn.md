# 项目整体概述

## 项目目标

这是一个面向金融长文档问答的工程基线，目标不是绑定某一轮排行榜，而是形成可复用的文档解析、检索、证据、计算、验证和恢复链路。

覆盖的主要文档类型包括金融合同、财务报告、保险条款、监管文件和研究报告。

## 主链路

题目加载 → 题型与策略识别 → 候选文档范围 → 文档内检索 → 证据选择与压缩 → Claim/选项原子化 → 证据绑定或计算 → 验证 → 失败分类与有界恢复建议 → 输出合同。

## 关键设计

### 1. 文档解析

MinerU 作为主要结构化解析来源，尽量保留页码、标题、表格和来源血缘。针对少量异常页面，只允许窄范围、页面级的解析器回退，不进行全局 Parser 切换。

### 2. 两级检索

先确定候选文档范围，再在候选文档内部检索证据。文档级范围和页内证据必须使用同一套 lineage，避免“找对答案但来源不可审计”。

### 3. 最小充分证据

在不破坏实体、年份、指标、单位、公式、选项、否定、条件和例外覆盖的前提下压缩上下文，减少长文档问答的噪声和 Token 成本。

### 4. Claim 级验证

复杂选项拆成原子 Claim，分别绑定主体、指标、时间、数值、条件和例外，再聚合为 SUPPORT、REFUTE 或 UNRESOLVED，避免只凭关键词重叠直接判断。

### 5. 失败与恢复

失败先区分缺证、血缘丢失、Binding、计算 Binding、模型输出、Provider、预算和运行完整性，再给出受限恢复建议。未知或高风险失败默认 fail-closed。

## 当前目录

- src/：核心实现。
- config/：运行和策略配置。
- scripts/：通用工具。
- tests/：离线核心回归。
- docs/：架构、接口、参考资料和历史。
- submissions/：仅保留历史基线入口说明。
